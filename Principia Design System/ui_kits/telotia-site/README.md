# Telotia site UI kit

The public surface for Telotia and the Principia product. Reads like the kernel's own documentation — a careful thinker speaking in their own voice — and never like a SaaS landing page.

## Screens (single-page, scrolled)

- **Hero** — name, one-paragraph thesis, constellation backdrop
- **The Organism** — chamber graph + the cycle of life
- **The Vocabulary** — Telos, Slice, Verdict, Mortality
- **Install** — the kernel's actual install block
- **Honest assessment** — what the dish demonstrates *and what it does not*
- **Footer** — the three repos in the dev-flow chain

## Design rules (site-specific)

- **No CTAs.** No "Sign up". No "Get started today". The site is an artifact, not a funnel.
- **No screenshots of "the product".** The product is a kernel. The visualization is the chamber graph.
- **Copy is taken from the kernel's actual prose.** The README, the ontology document, the release notes — these are the source.
- **The hero is dark.** The rest is parchment.
